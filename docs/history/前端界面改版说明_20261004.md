# 视界盾前端界面改版说明

日期：2026-10-04

## 设计与实现

先使用内置 imagegen 生图工具生成主界面与设置页参考图，再按参考图调整 PySide6 原生界面。内置工具不暴露模型选择参数，未通过外部 API 指定模型。没有把生成图片作为可交互界面，也没有增加网页渲染容器。

参考图采用浅灰底、细分隔线、适度留白与克制蓝色。主界面保留品牌文字、居中防护状态、主操作按钮和底部设置/后台运行；设置页将三个独立效果开关排为说明文字与右侧复选框，下方保留启动偏好和机主登记入口。状态圆点与文字同时表达运行、暂停和异常，主窗口允许调整大小。

实际文案按现有功能校正：提醒由旁观风险触发；启动偏好指打开软件后的行为，并非 Windows 开机启动。保存、取消、机主登记、关闭驻留托盘与无托盘退出沿用原有逻辑。三个效果开关仍分别持久保存，遮蔽选择下次启用时应用，音效和弹窗设置保存后用于后续提醒。

生成参考图和原生控件渲染预览保留在本机 `test_artifacts/ui_design_20261004/`，该目录被 Git 忽略，不包含真实桌面、聊天或人脸内容。运行界面不依赖这些图片。图片仅用于设计与视觉核对。
