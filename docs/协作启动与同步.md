# 视界盾：协作启动与同步

## 正式目录

本机正式源码目录：D:\ai比赛\VisionShield。摄像头和桌面模块继续独立运行，各自维护环境。本机通过忽略的目录联接复用旧环境和模型，不上传这些目录。组员克隆后要自行准备环境、模型，并由本人登记机主；不会下载你的面部模板。

## 摄像头模块

在视界盾开发目录执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-a.txt
.\.venv\Scripts\python.exe check_environment.py
```

MediaPipe模型准备步骤见A_今日具体操作指南.md。机主识别另需OpenCV Zoo的face_detection_yunet_2023mar.onnx和face_recognition_sface_2021dec.onnx，保存到本模块models目录；下载时验证模型文件，保留第三方许可。按A_自动机主识别操作指南.md运行模型检查和首次登记。

## 桌面模块

在视界盾桌面防护目录执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install numpy opencv-python mss PySide6 uiautomation comtypes rapidocr_onnxruntime
.\.venv\Scripts\python.exe -m pip install --force-reinstall --no-deps onnxruntime-directml==1.24.4
.\.venv\Scripts\python.exe prepare_fast_models.py
.\.venv\Scripts\python.exe -c "import onnxruntime as ort; print(ort.__version__, ort.get_available_providers())"
.\.venv\Scripts\python.exe hybrid_text_test.py --demo
```

默认ONNX后端不需要Paddle。若需要旧Paddle对照，另安装paddlepaddle、paddleocr，并运行prepare_models.py。requirements-extra.txt记录本机扩展包；两个ONNX Runtime发行包共享模块名，最后安装DirectML并检查实际provider。没有GPU时实测CPU速度，不套用其他电脑的性能数据。

上述安装是组员首次准备步骤，不代表已在所有新机器验证。直接运行界面会采集屏幕，仅使用虚构内容验收。

## 同步操作

推荐GitHub Desktop登录GitHub并克隆私有仓库。每个任务先同步main，再创建分支，开发、验证、提交、推送，最后创建PR；由另一名成员检查后合并。当前命令行Git尚未完成凭据授权，本次上传通过已连接的GitHub插件完成；本地仓库通过Git对象校验与远端保持相同历史。

助手后续修改按AGENTS.md同步到GitHub；日常手动修改仍需要你提交、推送，不会仅因保存文件自动上传。网络中断、授权失效或合并冲突时，保留本地工作并明确标记未同步。
