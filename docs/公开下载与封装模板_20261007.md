# 公开下载与封装模板

用户于2026-10-07授权开放GitHub下载。私有源码继续位于 `dujh413/VisionShield`，公开说明和发行资产位于 [VisionShield-Downloads](https://github.com/dujh413/VisionShield-Downloads)。两者分别管理，不公开私有源码和开发记录。

首个版本为 `v0.1.0-preview.1`，软件以 Windows x64 便携ZIP分发，完整解压后双击VisionShield.exe，目标电脑不需要Python。未来安装器在同一发行流程继续完善。

`packaging/release` 是可复用封装模板。`Build-Public.ps1` 调用既有构建、13项包验收和受限清理，然后 `package_public.py` 校验验收凭证及EXE摘要、排除个人数据、补齐使用说明与许可、记录版本和公共模型摘要，生成软件、模板、第三方对应源码ZIP及SHA256校验文件。同版本资产存在时拒绝覆盖。

Qt插件采集原先间接引入未使用的PDF、虚拟键盘和QML/Quick组件。本轮spec明确排除这些插件及其动态库，并排除应用不使用的FFmpeg插件；摄像头仍使用Windows采集路径。未修改人脸模型、身份门限或恢复代码。包内保留独立可替换的Qt/GEOS库及许可，对应源码以同一Release附件分发。

当前预览版仍有严重模糊、遮挡和小脸漏检/误检、完整后端内存较高，以及新电脑和持续实人联合验收尚未完成的问题。下载说明明确这些边界，不宣称全部场景500ms响应或已完成正式验收。

下载页使用GitHub Release Assets；GitHub自动生成的Source code不是Windows软件包。发布后验证未登录的下载入口、附件大小与摘要。未发布草稿或未完成附件上传不能记作公开下载完成。
