# 动态桌面防护与显示模式

## 输入框使用

使用统一入口 `VisionShield.py` 或重新构建后的软件，在主界面“敏感内容处理设置”中输入，再点击“启用防护”。修改输入不影响正在运行的模式，暂停后重新启用才生效。保存的输入可用于下次启动；原有自动启用偏好仍保留。单独运行开发控制面板 `视界盾桌面防护/desktop_guard.py` 时，使用“启动 / 重试”按钮。

| 输入 | 行为 |
|---|---|
| 非负整数字符，例如 `8`、`12` | 盒式模糊，半径为该数值，单位是物理屏幕像素 |
| 空字符串或仅空白 | 不处理敏感内容；主界面显示“检测与提示已启用（不遮蔽）” |
| 其他字符，例如 `遮挡`、`abc`、`12a` | 使用不透明深色矩形 |

盒式滤波使用边长 `2r+1` 的均匀平均核。半径 `0` 保留原像素；全角数字可输入。负号、小数点等非整数字符走深色遮挡分支。输入框最多接受128个字符，不将字符原文写入日志。

显示模式与现有风险触发逻辑配合：机主未确认、旁观风险、身份连接失效时处理敏感区域；可靠安全状态持续后恢复。空输入明确关闭内容处理，即使出现未知区域或异常也不绘制遮罩。此时采集、规则和状态诊断仍可运行。

遮蔽开关、提醒、应用范围与区域追踪保留当前main的实现。关闭遮蔽开关时，输入模式不会强制打开遮蔽。框选区域失配仍按原应用策略保护；对已裁切的应用区域，模糊不向范围之外添加边距，也不通过外接矩形填满被排除的前台窗口空洞。

模糊计算在后台线程进行，只保留最新请求。结果使用前验证目标区域像素是否仍然一致；未准备好或已变化时暂用深色覆盖，准备好后显示模糊图。风险存在而整屏尚未分析时，临时处理整屏；分析完成后细化到敏感及未知区域。

## 动态画面与有效性

- OCR结果不再要求整屏像素完全相同。对未变化区域保留有效结果，对变化区域及关联文字行保持临时处理；标签变化也使邻近值行失效。
- 差分使用精确像素比较，不忽略单字符变化。远距离小变化分别裁剪；面积、区域数量过大或达到刷新条件时回退整屏。
- 采集超过1.5秒未更新时不复用旧坐标。OCR快照超过10秒失效，拒绝未来时间、过期或倒序结果；稳定画面按5秒间隔重新提交，并定期整屏刷新。
- 空检测结果标记为未知，不作为没有敏感内容的完整性证明。该策略也会保守处理真正空白的画面。
- 身份消息要求有限且近期的发送时间；新会话在旧会话超时后接管，已经退休的会话不能再次覆盖状态。这个本机接口仍不构成身份认证边界。

以上阈值是当前原型默认值，需要按目标设备和场景验证。区域像素验证、OCR覆盖状态和实际模型漏检是不同问题，不能将有效缓存当作全部文字已被识别的证明。

## 诊断与复测

以下命令在仓库根目录及已准备依赖、模型的环境中执行：

```powershell
.\视界盾桌面防护\.venv\Scripts\python.exe .\VisionShield.py --diagnostics
```

输入 `8` 或 `遮挡` 后启用。使用虚构内容，分别检查单字符修改、光标闪烁、两个远距离区域变化、滚动、窗口移动、暂停与重试；另做空输入测试，确认内容保持原样。统一入口自动启动摄像头与OCR；只有独立开发控制面板需要另行运行身份发送器。

源码诊断日志在本模块忽略的 `records` 下；打包软件位于当前用户的 `LOCALAPPDATA/VisionShield/records`。包含状态CSV、每秒心跳和OCR元数据事件。记录每个返回结果是否接受、模式、区域数量、截图年龄、采集耗时、队列等待、差分、预处理、检测、裁剪和识别；心跳也记录最近有效模糊结果的计算耗时。状态CSV中的OCR耗时不再仅限被接受的结果。不要上传设备日志、截图、文字原文或面部模板。

日志中的计时没有覆盖显示器实际扫描输出，不能直接称为实际保护生效耗时。原型的真实GPU速度和模糊绘制体验需要在运行设备上复测；本改动没有替换OCR模型、引入TensorRT或实现共享内存传帧。

## 回归测试

```powershell
.\.venv\Scripts\python.exe -m unittest -v test_mask_effect test_content_state test_identity_bridge test_diagnostics test_capture_worker test_sensitive_rules test_incremental_ocr test_gui_effect
```

`test_gui_effect` 使用离屏Qt、虚构图像和模拟采集接口，不采集真实桌面。缺少PySide6时会明确跳过4项界面测试，不能将其计入已通过项目。2026-10-05对main的冲突适配验证包含实际PySide6/OpenCV，桌面142项、身份9项全部通过，无跳过项；覆盖主界面提交模式、后台传递、迟到与空结果、应用范围空洞、运行异常和清理。真实Windows采集排除、DPI与GPU性能仍需设备验收。本次合并源代码未重建exe；按现有构建流程重新构建后才包含修改。
