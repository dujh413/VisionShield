# 视界盾运行测试与修复报告

日期：2026-10-05。检查起点为8b5c54a提交的Windows便携测试版。

## 发现与修复

| 问题 | 修复 | 验证 |
|---|---|---|
| readyRead绑定前已缓冲的首包可能等待后续消息才处理 | 前端连接建立后主动排空首包 | 已缓冲消息的回归测试 |
| 服务握手期间的停止指令可能未被读取，取消启动仍加载模型 | 服务连接后先处理现有命令；已取消时跳过启动 | 启用后立即取消的实测 |
| 状态文字相同时人脸数量、遮罩块数变化不发送新状态 | 以完整状态字段判断是否更新 | 仅数量变化的回归测试 |
| 重复退出再次发送停止请求、重设停止超时 | 退出请求幂等；退出中的关窗直接接受 | 重复退出与关窗测试 |
| 错误格式的提醒字段可进入字符串信号 | 仅发送非空字符串提醒，仍接收有效状态 | 错误提醒字段测试 |
| 无终端exe的Python回调异常缺少可读记录 | 注册异常钩子，记录本机最近一次回调异常 | 无stderr时日志写入及覆盖测试 |

运行期回调错误记录在 `%LOCALAPPDATA%\VisionShield\runtime_error.log`，仅保留最近一次、限制堆栈长度，不累积历史。启动异常仍使用launch_error.log；此前该文件中的Qt DLL错误属于旧包记录，初次复测没有再次出现。

## 验证范围

源码侧78项桌面测试及9项摄像头测试通过。初版包11项检查通过后，针对边界问题增加回归覆盖。新版包再次验证摄像头/OCR并行、两轮启用停止、虚构文字识别与规则、公共人脸模型、用户数据位置、采集排除和原生文字依赖；另测启用后立即取消及开启遮蔽的运行/停止流程。本机验收记录位于被Git忽略的test_artifacts目录。

当前仍为Windows本机测试版；没有重新测量实人机主匹配准确率，也未证明所有其他电脑与应用均可用。测试不保存桌面截图、OCR原文或新增机主模板。源码、修复与文档同步至私有仓库，二进制包及本机日志不上传。

最终实测：新版包11项检查通过，两轮启用/停止完成；立即取消的源码程序约0.89秒退出，exe约3.05秒退出，均未触发强制超时。开启遮蔽的exe流程约13.89秒完成，观察到启动整屏保护、风险保护和OCR就绪，随后正常停止并关闭进程Job；该总时长包括启动与清理，并非推理时延。修正版位于本机dist/windows-fixed-20261005。
