# 视界盾代码审查与修复报告

日期：2026年10月4日。审查基线为`7de55c8`，完整软件功能所在分支为`feat/lightweight-tray-ui`。本次保留软件方向及本机环境、模型和机主模板，修复代码问题并增加回归测试，暂不进行.exe封装。

## 1. 审查范围

检查统一入口、原生界面、后台服务、摄像头身份与本人登记、采集、OCR、增量结果、敏感规则、遮蔽、恢复和资源生命周期，并检查仓库中的文字直读及独立测试脚本。

审查重点为：异步结果不能清除更新的保护；失联和过期不能被当作安全；停止及异常退出不能遗留识别进程；本人登记必须明确操作并保留旧模板直到成功；识别不确定内容不能直接当成普通文字；调试统计不能无限积累。

原有测试基线为桌面34项、摄像头身份7项，全部通过。审查发现其未覆盖部分异常、异步时效和登记情形。本次为相关问题补充复现及回归用例。

## 2. 问题、修复与验证

| 问题 | 修复行为 | 验证依据 |
|---|---|---|
| 旧OCR结果可能删除新画面已确认的敏感行 | 迟到结果只替换仍与源画面一致的区域，保留其他新结果 | 旧空结果不能删除新敏感行；新有效空结果仍能清除旧敏感行 |
| 标签变化时，未变化的邻近数字可能提前恢复 | 保存当前文字的邻近上下文，标签或相关区域变化时使值行待分析 | 标签跨行变化、不同字号标签和值的回归测试 |
| 桌面采集停滞但未抛异常时继续使用旧画面 | 超过1.5秒无有效采集即临时整屏保护 | 模拟采集停滞且机主安全时，仍进入整屏保护 |
| OCR过期但机主安全时没有进入保护 | 将OCR过期纳入保护条件，收到新结果后允许恢复 | 过期保护及新结果解除临时保护测试 |
| 分辨率变化后继续使用旧坐标 | 采集尺寸与当前Qt主屏核对；异常时整屏保护并提示重启防护 | 显示器尺寸不匹配测试；遮罩跟随屏幕几何变化 |
| 一个资源关闭失败，后续资源不再关闭 | 分别尝试所有资源清理，保留失败对象以便重试 | 单个close失败后，OCR、摄像头和日志仍尝试关闭 |
| 上次清理失败仍可能再次创建采集任务 | 清理未完成时阻止再次启动 | 清理失败后不得创建新采集对象的测试 |
| 启动或停止服务可能无限等待 | 启动30秒、停止15秒超时处理 | 未连接时停止也有超时；超时触发进程树清理 |
| 服务或前端异常退出后可能遗留模型子进程 | 使用Windows Job的关闭即终止进程树机制；绕过venv重定向启动器管理实际服务 | 原生父子进程测试；实际摄像头/OCR服务强制终止后的子进程检查 |
| 异常服务状态消息可能引发界面错误 | 检查JSON对象、状态枚举和说明字段类型 | 非对象、缺失字段及未知状态消息被忽略 |
| 登记进程突然退出后界面持续等待 | 检查进程存活，明确报告失败并禁用登记按钮 | 子进程退出的登记窗口测试 |
| 摄像头预览未就绪时可以点击登记 | 有效预览且单一可靠轨迹时才允许登记 | 初始化状态下不能登记 |
| 登记失败消息被旧预览覆盖 | 终态消息停止读取旧预览 | 错误后仍排队的预览不能覆盖失败提示 |
| 连续几何轨迹中的人物替换可能混入模板 | 新特征与首个样本比较；特征、轨迹或质量异常后取消本次采集，需本人重新点击 | 虚构同一人物可完成12样本；人物替换不保存且旧模板字节不变 |
| 无效人脸向量可能写入模板 | 拒绝零向量、NaN和无穷值，正常向量归一化 | 特征有效性与归一化测试 |
| 打开登记意外保存未点击“保存”的设置 | 登记入口关闭设置而不提交勾选项 | 登记操作不改变未保存的设置 |
| 启动探针曾暂时移除全屏保护 | 在不透明全屏遮罩下检查截图中预期色块，不撤掉遮罩 | 原生截图排除PASS；成功和失败探针均保持保护的测试 |
| `--semantic`指向尚未提供的模块 | 明确给出参数错误，默认规则路径继续可用 | 退出码2、无ModuleNotFoundError堆栈的测试 |
| Paddle对照路径中部分检测框没有识别结果时被遗漏 | 为未覆盖检测框补充零置信度结果 | 有一行正常识别时，其余未识别框仍按不确定内容保护 |
| NaN、无穷或超范围OCR置信度未被视为不确定 | 非有限及超范围置信度进入保守保护 | 四种无效置信度测试 |
| 文字直读到达行数/时间上限却报告完整返回 | 记录truncated；读取全部分离的可见文本范围 | 部分返回标记、分离可见范围及原生虚构文字测试 |
| 长期运行的两个独立诊断脚本累积统计列表 | 人脸耗时使用最近10000帧窗口，采集平均值改为累计和 | 代码检查、明确统计范围及主屏三帧检查 |

这些修复针对本次已经发现的代码问题。规则未覆盖的隐私类别、OCR模型漏检及摄像头视场限制仍属于后续模型与场景效果评估范围，不能通过代码回归测试推断其已全部解决。

## 4. 剩余限制与使用变化

1. 复杂整屏OCR的速度问题仍需UIA主链路集成和推理优化，本次不宣称普遍达到500ms识别。
2. 模糊遮蔽仍需在不同字体、距离和角度下开展辨认对照。规则模式不等于完整聊天语义识别。
3. 显示器尺寸不一致时保护停止在异常状态，需暂停后重新启用；多显示器仍待系统验收。
4. 本人登记遇到轨迹、质量或特征变化时，需确认本人并重新点击登记；日常机主重新识别仍自动读取持久模板。
5. 临时采集或OCR过期会扩大保护范围，恢复后仍按既定稳定等待控制。
6. 本机元数据记录、环境、模型、原始诊断输出和真实模板不上传。本报告只提交必要汇总。
