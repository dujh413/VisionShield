## 权限与规则

当前仅所有者和受邀成员可以访问源码及Release。未登录或无访问权限的访客得到404；不增加其他账户，不更改既有协作者权限。公开期间的权限说明不代表当前仍向访客开放。

main禁止强推和删除，适用于所有者。其他人修改main必须提交PR，至少一次审批、由CODEOWNERS指定的所有者审查、解决讨论；新提交撤销旧审批，最新提交由其他人批准。所有者保留正常直推权限，用于本地维护和已验证的小修改。日常不强推，不覆盖队友更新。

v*发行标签仅允许管理员创建、修改、删除。GitHub Actions默认只读令牌，不能批准PR；外部fork工作流需要审批。启用密钥扫描、密钥推送保护和私密漏洞报告。规则不能防止所有者账户被盗，所有者需自行保管登录和恢复信息。

## 后续正常维护

所有者仍可本地修改 → 调试/验证 → commit → push。队友以分支/PR协作；先同步最新main再开始，冲突要处理，不强推。仅保存文件不会自动更新GitHub。

软件更新还需要构建、13项包验收、必要场景测试、生成版本资产、发布新的Release。旧Release不自动改动；不覆盖同版本下载文件。软件ZIP、封装模板、第三方对应源码和SHA256SUMS一起发布。首次登记和设置留在使用者电脑。

旧构建清理由packaging/Build.ps1调用受限规则：验收通过才清理超过24小时的被替代产物，保留当前和最近一个已验收回退版本，跳过重解析点及运行中的包。
