# 私有下载与版本更新

源码仓库及Release保持私有。使用者先接受仓库邀请，再登录有权限的GitHub账号，打开[发行页面](https://github.com/dujh413/VisionShield/releases)。当前下载版本是`v0.1.0-preview.3`，在Assets中选择`VisionShield-Windows-x64-*.zip`；自动生成的Source code是源码，不能直接作为Windows软件运行。

完整解压ZIP，保留`VisionShield.exe`同目录的`_internal`，双击EXE启动。Windows 10/11 x64使用者无需安装Python。首次使用由本人在设置中登记机主，日常自动重新识别。未登录或无权限时返回404是正常访问保护。

同一Release提供软件ZIP、封装模板ZIP、第三方对应源码ZIP及SHA256SUMS。可使用PowerShell的`Get-FileHash -Algorithm SHA256`核对下载文件。自动化下载需显式指定版本，或从非草稿发行列表选择，支持预览版；`releases/latest`只查正式版本，不能用于判断本项目是否有预览版。

更新前完全退出旧软件，将新版解压到新的目录，避免混用不同版本的EXE和依赖。本机机主模板、设置和运行元数据保留在使用者数据目录，不复制到分发包。仅修改或推送源码不会更新已经下载的EXE，需要重新构建、验收并发布新的私有Release；不覆盖已有版本附件。

维护者构建见[Windows打包说明](Windows测试版打包说明.md)和[发行模板](../packaging/release/README.md)。下载、摘要、模型及EXE启动的云端复测见[Windows云端测试](Windows云端测试.md)和[验收报告](Windows云端验收报告_20261018.md)。旧VisionShield-Downloads仅保留历史版本，日常使用以主仓库发行页为准。
