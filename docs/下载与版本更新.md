# 下载与版本更新

软件及源码通过公开的 [VisionShield仓库](https://github.com/dujh413/VisionShield)提供，下载无需加入协作团队。

## 获取软件

在 [最新Release](https://github.com/dujh413/VisionShield/releases/latest) 的Assets中选择 `VisionShield-Windows-x64-v0.1.0.zip`，完整解压后双击VisionShield.exe。保留同目录的_internal，无需安装Python。自动生成的Source code只用于开发。

同一版本提供软件ZIP、封装模板ZIP、第三方对应源码ZIP和SHA256SUMS。使用PowerShell的 `Get-FileHash -Algorithm SHA256` 核对软件ZIP与校验文件。适用系统为Windows 10/11 x64，需要可用摄像头。

首次使用由本人在设置中登记机主。选择范围、遮蔽效果及提醒选项后启用防护。局部OCR只处理有效敏感命中，不能覆盖全部私人聊天语义；具体范围和限制见[显示模式](动态桌面防护与显示模式.md)。

## 更新

从托盘完全退出旧版，将新版解压到新的文件夹，不混用不同版本的EXE和依赖。个人模板及设置保留在Windows用户数据目录，更新后需重新选择目标窗口。公开版本与本机数据分开存储。

维护者修改源码后，正常测试、提交、推送即可；要更新可下载软件，仍需重新构建、验收并创建新的Release。不覆盖已有附件，旧下载版不会随源码保存自动改变。

构建见[打包说明](Windows测试版打包说明.md)和[发行模板](../packaging/release/README.md)。云端验证见[Windows云端测试](Windows云端测试.md)。
