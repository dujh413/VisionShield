# 视界盾：轻量后台软件设计

用户确认的全项目方向：最终交付内存占用小的后台式Windows `.exe` 软件，主界面保持简约。2026-10-04用户已要求封装测试版并更新仓库；当前提供整套系统的便携 exe 构建配置与本机测试包，使用与更新见[Windows测试版打包说明](Windows测试版打包说明.md)。此约定已写入仓库AGENTS.md。

## 当前入口与操作

源码环境准备完成后，双击仓库根目录的“启动视界盾.cmd”即可打开软件，不保留终端窗口。便携测试版直接双击软件目录中的 VisionShield.exe；正式安装器仍需后续新电脑联合验收。

启动脚本使用ASCII命令和CRLF换行，交由Launch.ps1处理中文路径。入口异常会在本机LOCALAPPDATA/VisionShield/launch_error.log记录启动堆栈并显示错误窗口，避免pythonw失败时无反馈。

从仓库根目录启动：

```powershell
& '.\视界盾桌面防护\.venv\Scripts\python.exe' '.\VisionShield.py'
```

只检查界面、避免启动采集和模型：

```powershell
& '.\视界盾桌面防护\.venv\Scripts\python.exe' '.\VisionShield.py' --preview
```

主界面仅保留名称、状态、启用/暂停防护、设置和后台运行。关闭窗口或点击后台运行后驻留托盘；托盘提供打开窗口、启用/暂停和退出。系统没有托盘时不隐藏窗口，关闭窗口即停止并退出。重复启动会唤回已有窗口。

设置保存到本机用户的QSettings配置中，包含“打开软件后自动启用防护”和“打开软件后直接驻留托盘”；均默认关闭。它们控制打开软件时的行为，不注册Windows开机启动。预览模式始终不加载防护服务，不会显示虚假的正在防护状态。

设置中的“防护效果”提供三个独立开关，默认全部开启：遮蔽敏感内容、音效提示、弹窗提示。可选择仅遮蔽、仅音效、仅弹窗或任意组合，也可全部关闭效果并保留检测及状态更新。关闭遮蔽时屏幕内容保持可见，界面明确显示“检测与提示已启用（不遮蔽）”；异常和启动阶段也不自动开启遮蔽。

音效与弹窗保存后立即用于后续风险提醒；遮蔽选择在下次启用防护时传给后台，运行中修改后需暂停再启用。取消设置不会保存更改，重启软件保留已保存选择。弹窗优先使用系统托盘通知；系统无托盘时使用单个非模态提示窗口，4秒后隐藏，不弹出逐条确认框。音效使用系统提示音，仍受系统声音设置控制。

首次本人登记：先暂停防护，在设置中选择“登记 / 更新机主”，确认预览里仅有本人后点击“开始本人登记”。采集12份清晰特征并仅保存到摄像头模块private/owner_templates.npz，不保存照片和视频。登记中关闭窗口即取消；已有模板在新登记完成前保留。日常启用自动读取模板，转头或低头后重新确认，无需重复登记。

## 内存与生命周期

- 前端仅使用PySide6控件和小图标，不加载OpenCV、NumPy、OCR或摄像头模型，也不循环截图。
- 启用时独立启动guard_service进程，统一管理桌面采集、OCR进程和CameraWorker摄像头身份进程。前端通过子进程状态消息更新界面，通过Qt本机通信发送停止请求，没有轮询定时器。
- 暂停向后端发送停止指令；服务先关闭遮罩、采集、OCR进程及接口，然后退出，释放后端模型和图像内存。前端驻留托盘。
- 退出等待上述清理完成再结束前端。前端退出造成管道关闭时，后端也执行清理。
- 主界面不显示实时摄像头/屏幕预览，不保留原文历史，不引入WebEngine或大型仪表盘。

前端低占用不代表防护运行时所有模型低占用。验收分别记录前端空闲、托盘驻留、防护运行和暂停后的工作集，不承诺所有电脑的固定数值。配置、日志、真实内容与运行截图保持本机保存。

## 当前整体流程

启动界面 → 启用防护 → 摄像头机主识别与桌面OCR并行 → 敏感规则判断 → 判断旁人/机主未确认风险 → 托盘通知、提示音和界面状态 → 强像素化模糊敏感行与待分析变化区域 → 风险消失并稳定1秒 → 恢复。

摄像头使用YuNet检测与SFace特征比对，连续5帧匹配才确认机主；没有模板、没有确认本人、出现第二张脸、状态过期或摄像头异常时进入保护状态。默认摄像头编号0，机主相似度阈值0.45；旧OpenCV不支持内存模型参数时，仅把公共模型复制到本机英文缓存路径，不复制人脸模板。

OCR使用现有本地ONNX后端。ContentIndex按64像素格核对变化；OCR返回时仅接受与最新桌面对应区域仍一致的敏感框。字符变化时将整条旧敏感行纳入待分析区，防止仅遮住新字符而露出旧前缀。超过时效或严重推理异常时临时整屏遮盖，不能把陈旧坐标用于新内容。

区域遮蔽按启动时提交的输入处理：非负整数控制均匀模糊半径，当前半径1–128优先使用OpenCL GPU；0保留原像素；空输入不处理；其他字符用不透明深色矩形。模糊未完成或内容变化时先深色覆盖，完成后绘制不透明模糊图，不通过透明度混合原文。很小半径不能保证文字不可读，应按目标内容选择强度。详细规则见[动态桌面防护与显示模式](动态桌面防护与显示模式.md)。遮罩排除截图机制仍需每次启动通过探针。此效果是视觉防护，不等同于特定观看角度的硬件防窥。

提醒仅在风险进入时触发，设置10秒通知冷却以减少连续误鸣；状态与保护逻辑不受冷却限制。系统静音或通知抑制可能影响系统通知显示，界面状态仍更新。运行元数据日志只在本机records保存，不包含OCR原文或人脸图像。

## 后续验收与封装

摄像头与OCR不再需要手动分别启动。“防护已启用”表示服务运行，实际机主状态、OCR状态及保护状态在主界面显示。规则覆盖手机号、邮箱、身份证校验和标签关联的凭证等；不宣称覆盖所有私人聊天语义。摄像头覆盖范围以实际视场为限，当前风险基线为未确认机主或多人，不宣称能准确判断所有人的视线方向。

当前PyInstaller便携测试版沿用VisionShield.py单入口，统一管理摄像头登记与检测、文字获取、规则和遮罩。使用Qt本机通信传递后台状态，避免无终端exe依赖标准输出。个人模板与日志写入用户数据目录，更新包不覆盖它们。正式安装器和新机器验证仍在后续阶段完成。
