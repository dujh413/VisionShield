# 视界盾 Windows 预览版

## 下载和启动

适用于 Windows 10/11 的64位电脑。需要可用的摄像头；模型和运行依赖已经随包提供，无需安装 Python。显卡加速可用时自动使用，不可用时回退。

源码和Release为私有。下载前先登录已获仓库访问权限的GitHub账号并接受邀请；未登录或未获授权时链接返回404。

下载带 `Windows-x64` 的 ZIP，完整解压至普通文件夹，双击 `VisionShield.exe`。请保留同目录的 `_internal`。更新前先退出旧版，再解压新版本至独立文件夹。

## 第一次使用

1. 打开设置，由本人操作登记机主。
2. 主界面选择模糊或深色遮挡，拖动水平滑杆即时调整强度；设置中的遮蔽、音效及弹窗可独立选择。
3. 如需只保护指定位置，暂停防护后框选局部区域，或点击目标窗口选择整窗保护。新局部选区随窗口移动和缩放，内容布局改变后请重新框选；软件重启后需重新选择目标窗口。
4. 启用防护。软件在后台并行检测旁观风险和敏感文字，风险消失并连续确认安全后恢复。

设置中的“框选区域内自动识别敏感内容”默认关闭，关闭时保护完整选区。开启后，风险出现时只处理选区内OCR命中的手机号、邮箱、证件号、验证码和账号等标签关联内容；其他位置保持清晰。等待识别、识别异常或未命中时不整区遮盖，识别漏检的内容不会自动保护。整窗策略不受该选项影响。尚不能完整识别所有私人聊天语义。首次更新到此版本后，建议重新框选以替换旧版特征追踪配置。

关闭主窗口会保留托盘运行。需要完全退出时使用托盘退出；暂停防护会停止后端采集和推理。更新保留当前 Windows 用户已有的本人登记和设置。

## 数据

图像和文字分析在本机处理。正常运行不保存摄像头画面、桌面截图或聊天原文。本人登记模板和设置保存在使用者自己的电脑，不随发行包提供。运行元数据日志用于诊断状态和耗时，默认不记录聊天原文。

## 当前预览版范围

主要验证主显示器及可见文字保护。严重模糊、遮挡和远处小脸仍可能漏检或误检；不能保证所有场景500ms内响应。完整识别后端内存仍较高，新电脑兼容性和持续双人准确率需要更多实测。本版不是已完成全部验收的正式版。
