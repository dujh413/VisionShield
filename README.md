# VisionShield · 视界盾

仓库及Release现为私有，仅账号所有者和受邀成员可访问。后续开发同步与发行沿用此可见性。

面向公共学习与办公场景的 Windows 屏幕内容防护软件。摄像头检测旁观风险，本地 OCR 定位敏感文字，在用户指定范围内模糊或深色遮蔽；风险稳定消失后恢复。遮蔽、音效和弹窗可独立选择。

## 下载与使用

[下载发行版](https://github.com/dujh413/VisionShield/releases) · [封装模板](packaging/release/README.md)

在 Release 的 Assets 下载带 **Windows-x64** 的 ZIP，完整解压后双击 `VisionShield.exe`，保留同目录的 `_internal`。目标电脑无需安装 Python。GitHub 自动生成的 Source code 是源码，不能直接作为 Windows 软件运行。

首次使用在设置中由本人登记机主，然后启用防护。需要限定范围时，先暂停，再框选局部区域或点击目标整窗。主窗口关闭后驻留托盘，完全退出使用托盘菜单。更新前退出旧版，将新版解压到新文件夹；本机用户设置和登记模板保留。

局部选区绑定所点窗口内的相对位置，随窗口移动和缩放；内容布局改变后需重新框选，软件重启后需重新选择窗口。设置中的“框选区域内自动识别敏感内容”默认关闭：关闭时保护整个选区；开启后只处理本地OCR识别命中的敏感文字，其余保持清晰，等待识别或未命中时不整区遮盖。漏检的内容不会自动保护。整窗选择不受该开关影响，识别范围及测试说明见[动态桌面防护](docs/动态桌面防护与显示模式.md)。

局部OCR先裁出有效选区再识别，减少整屏缩放及其他应用文字的干扰；手机号、邮箱文字未变化时，附近的光标闪烁不会清空命中。状态中显示已读取行数和有效敏感条数，选区未绑定时提示重新框选。手机号支持常见空格、连字符及点号分组格式。

当前为 **预览版**。主要验证主显示器的可见文字保护；严重模糊、遮挡、远处小脸仍可能漏检或误检，不能保证全部场景 500ms 响应。完整识别后端峰值约 1.9GB，低内存目标、持续双人效果及新电脑兼容性仍待完善。

## 开发与协作

统一源码入口为 `VisionShield.py`。启动和暂停状态不加载模型；启用后在独立进程并行运行摄像头与 OCR，暂停时释放后端资源。

| 路径 | 职责 |
|---|---|
| 视界盾开发 | YuNet 检测、SFace 机主特征与身份状态 |
| 视界盾桌面防护 | 原生 Qt 界面、OCR、敏感规则、区域追踪与遮罩 |
| packaging | EXE 构建、验收、旧构建清理、发行模板 |
| docs | 当前方案、操作指南与维护说明 |

首次克隆、环境、运行和提交见[协作启动与同步](docs/协作启动与同步.md)。后续可在本地正常修改、调试、提交并推送；仅保存文件不会自动上传。所有者可维护 main，受邀队友通过分支及 PR 提交，由所有者审核。重新打包并发布新版本后，下载的软件才会更新；旧 Release 不会随源码修改自动变化。

## 数据、反馈与许可

正常运行不保存摄像头画面、桌面截图或聊天原文；机主模板仅在使用者电脑上生成。Git 不包含环境、模型、登记模板、截图或日志。包内公共模型和第三方依赖附许可，对应源码随 Release 提供。

通过 [Issues](https://github.com/dujh413/VisionShield/issues)反馈版本、Windows 版本、操作和现象。不要公开个人模板、真实聊天、验证码或密钥；敏感安全问题见 [SECURITY.md](SECURITY.md)。
