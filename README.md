# VisionShield · 视界盾

Windows 屏幕隐私防护软件。在公共学习、共享办公等环境下，通过摄像头判断旁观风险，在用户选择的窗口或局部范围内模糊、遮挡敏感内容，并提供可选音效和弹窗提醒。

## 下载

**[下载 Windows x64 软件包](https://github.com/dujh413/VisionShield/releases/download/v0.1.0/VisionShield-Windows-x64-v0.1.0.zip)** · [Release与校验文件](https://github.com/dujh413/VisionShield/releases/latest)

适用于 Windows 10/11 64位系统。完整解压ZIP后双击 `VisionShield.exe`，保留同目录的 `_internal`，无需安装Python。GitHub自动生成的Source code是源码，不是Windows软件包。

## 功能

- 本人登记机主，日常自动比对；检测到旁观风险后处理保护范围，安全状态稳定后恢复。
- 框选局部区域或选择一个具体窗口，保护范围随窗口移动；重启软件后重新选择目标窗口。
- 模糊与深色遮挡两种效果，水平滑杆即时调整模糊强度；遮蔽、音效、弹窗独立开关。
- 可选局部敏感文字识别：本地OCR识别手机号、邮箱、有效身份证号，以及验证码、账号、姓名、地址等标签关联内容，只处理选区内的有效命中。
- 后台托盘运行；暂停后释放摄像头及识别后端，退出通过托盘菜单完成。

## 第一次使用

1. 打开设置，由本人操作登记机主。
2. 暂停防护后，框选局部区域或选择整窗；调整遮蔽效果、模糊程度及提醒选项。
3. 保存设置，启用防护。若提示范围未定位，暂停后重新选择。

“框选区域内自动识别敏感内容”默认关闭：关闭时保护整个选区；开启后仅处理OCR命中的敏感文字，其余保持清晰。等待识别、识别异常或漏检的内容不会自动保护。整窗策略不受该开关影响。窗口内滚动、布局变化或缩放后，敏感文字位置需要重新识别。

## 隐私与适用范围

图像与文字分析在本机完成，正常运行不保存摄像头画面、桌面截图或聊天原文。个人机主模板在使用者电脑生成，不随发行包提供；诊断日志记录状态与耗时。

当前主要支持主显示器上的可见文字保护，尚未实现通用私人聊天语义分类。模糊、遮挡、远处小脸可能影响识别；不保证全部场景500ms响应。识别后端仍需较多内存，持续双人检测及更多设备兼容性正在完善。软件遮蔽对机主同样可见，不是按观看角度实现的硬件防窥。
