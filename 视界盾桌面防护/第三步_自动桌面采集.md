# 第三步：自动采集主显示器

本轮只运行screen_capture_test.py，不运行desktop_guard.py。不启动OCR、机主识别或遮罩，不保存截图。

## 1. 运行

在PowerShell执行：

```powershell
Set-Location -LiteralPath 'D:\ai比赛\VisionShield\视界盾桌面防护'
.\.venv\Scripts\python.exe screen_capture_test.py
```

预览每500毫秒获取一次主屏画面，顶部显示帧编号、原始采集尺寸和采集耗时。大屏仅缩小预览，原始数据不缩小。500毫秒是目标采集间隔，超慢采集时不会积压旧帧。

## 2. 按顺序验收

1. 打开记事本，输入虚构文字，例如：测试手机号13800138000，验证码246810。
2. 将记事本放在主显示器上，观察预览中是否出现相同文字。此阶段只显示像素，不识别文字。
3. 移动、缩放记事本窗口，观察预览是否自动变化。
4. 切换聊天窗口或另一个应用，观察新窗口是否出现。
5. 用虚构消息触发通知，检查可见通知是否进入预览。
6. 确认预览原始尺寸与主屏物理分辨率一致，画面方向、颜色正确。
7. 选中预览窗口后按Q/Esc或关闭窗口退出，再运行一次，确认可重新采集。

预览窗口本身也在主屏上时，会出现画面套画面，这是当前调试窗口进入截图的正常结果，不代表采集错误。可把预览放到副屏避免递归；本阶段仍只采集主屏。遮罩排除采集留到第六步单独验证。

## 3. 输出结构

- frame_id：本次运行递增帧号。
- captured_at：本机单调时钟时间，用于计算延迟，不是日历时间。
- monitor_rect：主屏left、top、width、height，使用物理像素。
- image：内存中的uint8 BGR三通道图像。

退出后终端只输出帧数、采集耗时、实际平均间隔等元数据，不含截图和桌面原文。

不需要可视预览时可运行：

```powershell
.\.venv\Scripts\python.exe screen_capture_test.py --check
```

这会自动采集3帧并退出，只检查尺寸、类型、帧编号和时间，不能证明通知内容或颜色显示正确。

## 4. 本轮完成标准

- 主屏尺寸正确；窗口切换、移动与通知能够自动更新。
- 不需要手动截图；帧编号递增。
- 能正常退出并再次启动。
- 没有生成截图文件。

若出现黑屏、错误主屏或尺寸不符，保留终端报错及实际显示器设置，先修复本步再接OCR。某些受保护窗口可能无法被普通屏幕采集捕获，需要单独记录。
