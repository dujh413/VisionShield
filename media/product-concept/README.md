# 视界盾 30 秒产品概念视频

成片为 1920×1080、16:9、30fps、30 秒的 H.264 MP4，带原创立体声配乐。视觉沿用当前原生软件的灰白和深绿配色，以透视投影、悬浮窗口、镜头推进、功能模块放大和运动叠化呈现功能。

本工程只生成媒体，不修改软件行为，不启用摄像头或 OCR 后端，不读取个人模板、真实桌面或聊天。软件界面由当前 Qt 源码配合临时设置、虚构身份状态离屏生成；内容演示为虚构笔记。风险与恢复经过动画编排，不能作为响应速度、检测准确率或实人效果的证据。

## 分镜

| 时间 | 画面 | 当前软件功能 |
|---|---|---|
| 0–5.5 秒 | 主界面在空间中转入，后方设置页形成层次 | 本地检测、主界面、后台运行 |
| 5.5–11.5 秒 | 所选区域随模拟风险模糊，再恢复；范围外清晰 | 人脸与文字检测、指定范围保护、稳定安全后恢复 |
| 11.5–18 秒 | 镜头从主界面推进到滑杆，弱到强，再切深色 | 主界面水平滑杆、模糊／深色切换 |
| 18–24 秒 | 设置页转入，三个原生开关放大，弹窗开关切换 | 遮蔽、音效、弹窗独立选择 |
| 24–30 秒 | 主界面与设置页并列收束，品牌与预览版说明 | Windows 原生软件、托盘驻留 |

选择范围需先暂停防护。局部追踪失配时暂停该选区并提示重选；视频未演示自动扩大到整屏。主界面不带实时摄像头预览。当前远处小脸、遮挡、持续双人识别仍有边界；本片没有将这些能力表述为已全面验证。

## 文件与修改入口

| 文件 | 用途 |
|---|---|
| `storyboard.json` | 各场景时间、标题、副标题、演示标识 |
| `capture_ui.py` | 从仓库当前 `app_shell.py` 离屏导出真实控件布局和受控状态 |
| `render.py` | 镜头角度、悬浮轨迹、缩放、转场、版式和虚构笔记 |
| `soundtrack.py` | 原创合成配乐；修改和弦、分解音、转场时间点 |
| `Render.ps1` | 重新导出界面、配乐、渲染并验证 |
| `verify.py` | 完整解码、900 帧、时长、分辨率、音轨、fast-start 检查 |

`output/` 是忽略的本地生成目录，包含 MP4、音轨、受控界面纹理、关键帧、联系表和验证结果。源码同步 GitHub；生成的截图和大体积成片不提交源码 Git 树。软件主界面更新后，重新运行 `capture_ui.py`，再检查放大区域与文字排版。界面原生状态是演示状态，未启动真实防护服务。

片中文字直接绘入帧，无需额外字幕文件。风格与内容可通过源码修改，未使用外部视频、人物素材、商标标志或第三方歌曲。所用字体是 Windows 微软雅黑和 Segoe UI，字体文件不随源码分发。

## 在 Windows 仓库中渲染

在完整 VisionShield 仓库内执行，Python 3.12 为本次验证环境。视频依赖放在媒体工程独立环境，不影响软件环境：

```powershell
Set-Location -LiteralPath 'D:\ai比赛\VisionShield\media\product-concept'
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\Render.ps1
```

也可指定已安装所需依赖的解释器：

```powershell
.\Render.ps1 -Python '绝对路径\python.exe'
```

先检查静态画面可用 `-PreviewOnly`。无声版可用 `-Silent`。`imageio-ffmpeg` 提供本地编码器；若已有完整 ffmpeg，可以向 `render.py` 传 `--ffmpeg '绝对路径\ffmpeg.exe'`。只含 VP8 的 Playwright ffmpeg 不适用此 MP4 工程。

默认输出为 `output/VisionShield_Concept_30s_1080p.mp4`。其他路径可通过 `render.py --output` 指定。`--scale 0.5` 仅用于低分辨率动作预览，正式成片使用默认值 1。镜头版式按 1920×1080 和 30 秒设计；更改整片时长或比例需一并调整版式、配乐和验证脚本。

首次准备依赖需联网，之后可离线渲染。生成流程内存不随帧数持续累积；编码使用 rawvideo 管道，每帧处理后交给 ffmpeg。
